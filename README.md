# Movie Platform - Dynamic Data Management System

A complete movie management platform with FastAPI backend, MySQL database, JWT authentication, and pure HTML/CSS/JS frontend.

## Features

- 🔐 Authentication & Role-Based Access (Admin/Client)
- 📊 Dynamic CRUD operations on movie data
- 🔍 Advanced search, filters, and pagination
- 📈 Dashboard with analytics and statistics
- 📁 JSON data import/export
- 🎨 Responsive custom CSS (no frameworks)
- ⚡ FastAPI with SQLAlchemy ORM

## Tech Stack

- **Backend**: FastAPI, SQLAlchemy, PyMySQL
- **Frontend**: HTML, CSS, JavaScript (vanilla)
- **Database**: MySQL
- **Authentication**: JWT with password hashing (pbkdf2_sha256)
